llama-server 程序

llama.cpp 的发布包分 CPU 版与 GPU 版（CUDA / Vulkan / ROCm 等）。运行方式为 GPU 时使用 GPU 版；为 CPU 时使用 CPU 版，未配置 CPU 版则用 GPU 版并禁用 GPU。可填写程序文件或其所在目录，留空使用系统 PATH 中的 llama-server。

llama.cpp 更新

打开页面时会检测一次 GitHub 发布，也可手动检测。更新会按当前程序目录中的文件识别包类型（CPU / CUDA / Vulkan / ROCm 等），下载并校验后替换程序目录中的文件；替换时会停止使用该程序的实例，完成后自动重新启动。新版本无法运行时自动还原。程序来自系统 PATH 时不会自动更新。

模型目录
支持共享目录：Windows 填 \\主机\共享\目录（或映射的网络驱动器，选择器中输入 \\主机 可列出共享）； Linux / macOS 需先挂载 SMB / NFS，可直接填挂载点，或填 smb://主机/共享、nfs://主机/导出路径、主机:/导出路径 自动匹配已挂载的位置。网络目录读取超过 10 秒会跳过。
网络
代理地址留空时自动跟随系统代理（环境变量 HTTPS_PROXY 等，以及 Windows / macOS 系统设置中的代理，如 Clash、v2rayN 的“系统代理”模式）。GitHub 的代理与下载镜像在上方「llama.cpp 更新」中设置。
运行
推荐配置 （填入内存、显存并选择模型，生成最适合这台硬件的 llama-server 启动命令）

读取模型文件中的层数、注意力结构、专家权重等信息，精确估算权重、KV 缓存与计算缓冲的占用，按“全部放 GPU → MoE 专家放 CPU → 部分层放 GPU → 纯 CPU”的顺序选出最快且放得下的方案。默认填入本机检测到的硬件，可改成其它机器的配置。
